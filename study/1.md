#### 自定义 Runnable

在 LCEL 中，`Runnable` 是可被调用和组合的执行单元。自定义 Runnable 适用于在提示词、模型、输出解析器之间加入确定性的业务转换，例如补充指令、清洗输入或整理输出。

#### 泛型类型约束

`Runnable[Input, Output]` 用泛型描述输入和输出类型：

```python
Runnable[str, str]
```

表示该对象接收字符串并返回字符串。当前 `PrefixRunnable` 的输入是原始文本，输出是拼接前缀后的文本。

#### 最小实现

继承 `Runnable` 后，至少实现 `invoke()`：

```python
from typing import Any

from langchain_core.runnables import Runnable, RunnableConfig


class PrefixRunnable(Runnable[str, str]):
	def __init__(self, prefix: str) -> None:
		self.prefix = prefix

	def invoke(
		self,
		input: str,
		config: RunnableConfig | None = None,
		**kwargs: Any,
	) -> str:
		return f"{self.prefix}{input}"
```

`input` 是本次调用的业务输入；`config` 用于传递运行配置；`**kwargs` 用于兼容 Runnable 调用约定。`invoke()` 的返回值必须符合声明的输出类型。

#### 调用方式

```python
runnable = PrefixRunnable("请翻译为英文：")
result = runnable.invoke("苹果")

print(result)
# 请翻译为英文：苹果
```

#### 在 LCEL 中组合

Runnable 可使用 `|` 串联。前一个节点的输出必须能够作为后一个节点的输入：

```python
chain = PrefixRunnable("请翻译为英文：") | model | StrOutputParser()

print(chain.invoke("苹果"))
```

执行顺序为：输入文本 → `PrefixRunnable` 拼接前缀 → `ChatOpenAI` 调用模型 → `StrOutputParser` 提取文本内容。

#### 异步、批处理与流式调用

只实现 `invoke()` 时，Runnable 仍可使用默认的 `ainvoke()`、`batch()` 和 `stream()` 行为。若底层操作本身支持原生异步、批量请求或增量输出，再分别重写对应方法以获得更合适的执行方式。

#### 模块组织

Python 的点号导入要求目录和模块名符合标识符规则。`03-LCEL`、`05-custom-runnable.py` 含有连字符或以数字开头，不能作为 `from ... import ...` 的模块路径；因此将可复用类放在 `custom_runnable.py`，并从同目录导入：

```python
from custom_runnable import PrefixRunnable
```
